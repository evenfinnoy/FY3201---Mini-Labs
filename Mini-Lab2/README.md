# Mini Lab 2

This folder contains all the relevant files for plotting the CSV data used in the report. 

## Folders
The folders here, ex. ``Òslo``, contain the CSV data for that place and the exported plots.

## Python files
The main file is ``plot_climate.py``. This used the two other python files. 

- ``climate_common.py`` is a file which checks for data, imports the CSV data.
- ``climate_plots.py`` is the file that actually creates the plots, and all modifications of them.
